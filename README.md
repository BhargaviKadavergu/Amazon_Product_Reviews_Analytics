# Amazon Product Reviews Analytics

## Objective
Build a sentiment analysis model for Amazon product reviews and recommend similar products.

## Features
- Data preprocessing
- Feature engineering
- NLP preprocessing
- TF-IDF Vectorization
- Logistic Regression
- Sentiment Prediction
- Product Recommendation
- Streamlit Deployment

## Dataset
Columns Used
- reviewText
- overall
- productTitle
- reviewerID
- category
- reviewTime

## Technologies
Python
Pandas
NumPy
Scikit-learn
NLTK
Matplotlib
Seaborn
Streamlit

## Run Notebook
Open AmazonProductReviewsAnalyticsCapstoneProject.ipynb
Run all cells.

## Run App
streamlit run app.py
